| **ADHD IN YOUR 6-YEAR-OLD**                                           |
|                                                                       |
| A Comprehensive Catalogue of Signs to Watch For                       |
+-----------------------------------------------------------------------+

*A parent's reference guide*

This document is for informational purposes only and is not a diagnostic
tool.

Always consult a qualified healthcare professional for evaluation.

How to Use This Guide

ADHD (Attention Deficit Hyperactivity Disorder) presents differently in
every child. Many of the behaviours listed here are perfectly normal in
young children --- what distinguishes ADHD is the **intensity,
frequency, and persistence** of these behaviours, and the degree to
which they interfere with daily life.

For an ADHD evaluation to be considered, symptoms typically need to be
present for at least six months, appear in more than one setting (home
and school), and cause meaningful difficulty in social, academic, or
daily functioning.

This catalogue organises signs into seven categories. As you read
through them, you might keep mental note of which ones resonate with
your son's everyday experience.

  -----------------------------------------------------------------------
  **INATTENTION --- 10 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 👂 | **Seems not to listen when spoken to directly**                   |
|   |                                                                    |
|   | You call his name multiple times and he appears to be in his own   |
|   | world, even when there are no obvious distractions. This goes      |
|   | beyond typical childhood daydreaming in its frequency and          |
|   | intensity.                                                         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 📚 | **Difficulty following multi-step instructions**                  |
|   |                                                                    |
|   | Struggles to complete a sequence like "put on your shoes, grab     |
|   | your backpack, and meet me at the door." Often completes the first |
|   | step and then loses track of what comes next.                      |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🔍 | **Loses things constantly**                                       |
|   |                                                                    |
|   | Jackets, shoes, lunchboxes, toys, school papers --- they go        |
|   | missing with remarkable regularity. Items are left behind in every |
|   | room, at school, and at friends' houses.                           |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎯 | **Difficulty sustaining attention on tasks**                      |
|   |                                                                    |
|   | Worksheets, homework, chores, or even board games become abandoned |
|   | midway. Attention drifts within minutes unless the activity is     |
|   | intensely stimulating.                                             |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💨 | **Easily distracted by irrelevant stimuli**                       |
|   |                                                                    |
|   | A bird outside the window, a distant sound, a pattern on the wall  |
|   | --- things other children would filter out pull his focus away     |
|   | instantly.                                                         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🧩 | **Trouble organising tasks and activities**                       |
|   |                                                                    |
|   | Getting ready for school, packing a bag, or tidying up a room      |
|   | feels overwhelming. He may not know where to start, or will jump   |
|   | between tasks without finishing any.                               |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| ⚠️ | **Makes careless mistakes in schoolwork**                         |
|   |                                                                    |
|   | Skips questions, misreads instructions, writes answers in the      |
|   | wrong place. The errors aren't from lack of understanding but from |
|   | rushing or losing focus partway through.                           |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🚫 | **Avoids or dislikes tasks requiring sustained mental effort**    |
|   |                                                                    |
|   | Homework, reading assignments, or puzzles that require             |
|   | concentration are met with strong resistance, frustration, or      |
|   | procrastination.                                                   |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💭 | **Frequently daydreams or zones out**                             |
|   |                                                                    |
|   | Stares off into space during class or conversation. May appear     |
|   | "spacey" or lost in thought far more often than his peers.         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🔄 | **Forgets daily activities and routines**                         |
|   |                                                                    |
|   | Consistently forgets to brush teeth, put away dishes, or bring     |
|   | items to school --- even routines he's done hundreds of times.     |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **HYPERACTIVITY --- 8 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 🏃 | **Constantly in motion**                                          |
|   |                                                                    |
|   | Running, jumping, climbing on furniture, bouncing while walking.   |
|   | There's a relentless physical energy that rarely winds down, even  |
|   | in calm settings.                                                  |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🪑 | **Fidgets and squirms when seated**                               |
|   |                                                                    |
|   | Can't stay still at meals, during class, or at the doctor's        |
|   | office. Hands are always moving, feet are swinging, body is        |
|   | shifting.                                                          |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💺 | **Leaves seat when expected to stay**                             |
|   |                                                                    |
|   | Gets up and wanders during class, during meals, during church or   |
|   | events. He's up and moving when every other child stays put.       |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🔊 | **Talks excessively**                                             |
|   |                                                                    |
|   | A continuous stream of chatter, narration, questions, and          |
|   | commentary. May talk through movies, quiet time, or even when      |
|   | alone.                                                             |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🔋 | **Appears "driven by a motor"**                                   |
|   |                                                                    |
|   | Adults often describe the child as being "on the go" from the      |
|   | moment he wakes up until he crashes at bedtime. There's very       |
|   | little idle time.                                                  |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🔇 | **Difficulty playing or working quietly**                         |
|   |                                                                    |
|   | Every activity comes with sound effects, humming, tapping, or      |
|   | running commentary. Quiet play is extremely rare.                  |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🗣️ | **Blurts out sound effects or noises**                            |
|   |                                                                    |
|   | Makes random sounds, hums, clicks, whistles, or provides a         |
|   | soundtrack to everything he does. This often happens               |
|   | unconsciously.                                                     |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🧗 | **Climbs on things inappropriately**                              |
|   |                                                                    |
|   | Scales bookshelves, stands on chairs, climbs countertops. Does     |
|   | this in places and situations where it's clearly not appropriate   |
|   | or safe.                                                           |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **IMPULSIVITY --- 7 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| ✋ | **Blurts out answers before questions are finished**              |
|   |                                                                    |
|   | In class or at home, he shouts out responses before the question   |
|   | is complete. He can't seem to hold back even when reminded to      |
|   | wait.                                                              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| ⏳ | **Extreme difficulty waiting his turn**                           |
|   |                                                                    |
|   | Lines, board games, group activities, conversations --- waiting is |
|   | physically uncomfortable. He may push ahead, skip turns, or melt   |
|   | down.                                                              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💬 | **Interrupts others frequently**                                  |
|   |                                                                    |
|   | Cuts into conversations between adults, talks over friends,        |
|   | inserts himself into others' activities without being invited.     |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎲 | **Acts without thinking about consequences**                      |
|   |                                                                    |
|   | Runs into the street, touches hot things, jumps from heights, hits |
|   | when frustrated --- the action happens before any thought about    |
|   | what could go wrong.                                               |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💥 | **Grabs things from others**                                      |
|   |                                                                    |
|   | Takes toys, food, or materials from classmates and siblings        |
|   | without asking. Doesn't seem to register that it's someone else's  |
|   | possession.                                                        |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🛑 | **Difficulty stopping a behaviour when asked**                    |
|   |                                                                    |
|   | When told to stop doing something, he may acknowledge the          |
|   | instruction but continues anyway, almost as if the brakes don't    |
|   | work.                                                              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💸 | **Makes impulsive choices about food, play, purchases**           |
|   |                                                                    |
|   | Wants everything he sees immediately. Struggles to delay           |
|   | gratification or consider whether a choice is wise.                |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **EMOTIONAL REGULATION --- 7 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 🌋 | **Intense emotional reactions disproportionate to the situation** |
|   |                                                                    |
|   | A small setback --- losing a game, a sibling touching his toy ---  |
|   | triggers an explosion of anger, crying, or screaming that seems    |
|   | vastly out of proportion.                                          |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 😞 | **Low frustration tolerance**                                     |
|   |                                                                    |
|   | Gives up quickly on tasks that are even slightly challenging. A    |
|   | puzzle piece that doesn't fit or a shoe that won't tie can trigger |
|   | a full meltdown.                                                   |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎢 | **Rapid mood shifts**                                             |
|   |                                                                    |
|   | Moves from delighted to furious to giggling within minutes, often  |
|   | with no clear trigger. Emotional regulation is a significant daily |
|   | challenge.                                                         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 😭 | **Difficulty calming down once upset**                            |
|   |                                                                    |
|   | Once the emotional storm starts, it takes a long time to pass.     |
|   | Standard calming techniques (deep breaths, counting) may not work  |
|   | well.                                                              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💔 | **Takes criticism or correction very hard**                       |
|   |                                                                    |
|   | Even gentle redirection or constructive feedback can feel like a   |
|   | devastating blow. He may cry, shut down, or lash out in response.  |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🤔 | **Struggles to recognise emotions in self and others**            |
|   |                                                                    |
|   | May not be able to name what he's feeling, or may misread social   |
|   | situations because he doesn't pick up on others' emotional cues.   |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💪 | **Strong sense of injustice or unfairness**                       |
|   |                                                                    |
|   | Becomes extremely upset when things feel "unfair," even when the   |
|   | situation is perfectly reasonable. Rules must apply equally or     |
|   | it's perceived as a personal attack.                               |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **SOCIAL & PEER INTERACTIONS --- 6 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 👥 | **Difficulty making or keeping friends**                          |
|   |                                                                    |
|   | Other children may avoid playing with him because of his           |
|   | intensity, bossiness, or inability to share and take turns.        |
|   | Friendships may be short-lived.                                    |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎮 | **Dominates group play or won't follow rules**                    |
|   |                                                                    |
|   | Insists on being the leader, changes the rules mid-game, or quits  |
|   | when things don't go his way. This makes cooperative play very     |
|   | difficult.                                                         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 👋 | **Misses social cues and boundaries**                             |
|   |                                                                    |
|   | Stands too close, talks too loudly, doesn't notice when a friend   |
|   | is upset or wants to stop playing. Personal space and social       |
|   | conventions are hard to read.                                      |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💢 | **Plays too rough without realising it**                          |
|   |                                                                    |
|   | Hugs too hard, pushes when excited, tackles during tag. He doesn't |
|   | intend to hurt anyone but has difficulty moderating physical       |
|   | intensity.                                                         |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 😟 | **Seems immature compared to peers**                              |
|   |                                                                    |
|   | Emotional and social behaviour may seem like that of a younger     |
|   | child. He may gravitate toward playing with younger kids who are   |
|   | more tolerant of his style.                                        |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🏆 | **Struggles with losing or not being first**                      |
|   |                                                                    |
|   | Competitions, races, even lining up for lunch --- not being first  |
|   | or winning triggers intense distress. Sportsmanship is a real      |
|   | challenge.                                                         |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **SCHOOL-SPECIFIC --- 7 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 📝 | **Inconsistent academic performance**                             |
|   |                                                                    |
|   | Brilliant and engaged one day, completely unfocused the next.      |
|   | Teachers may say "He's so smart but just won't apply himself."     |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🗂️ | **Desk, backpack, and cubby are chaotic**                         |
|   |                                                                    |
|   | Papers crumpled at the bottom of the bag, broken pencils, missing  |
|   | supplies. Organisation is a consistent struggle.                   |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🚧 | **Difficulty with transitions between activities**                |
|   |                                                                    |
|   | Moving from recess to reading, or from art to maths, creates       |
|   | resistance or disruptive behaviour. Shifting focus is genuinely    |
|   | hard.                                                              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 📋 | **Doesn't complete classwork in the allotted time**               |
|   |                                                                    |
|   | While other children finish assignments, he's still on the first   |
|   | few questions --- not because it's too hard, but because focus     |
|   | drifted repeatedly.                                                |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🏫 | **Frequent teacher reports about behaviour**                      |
|   |                                                                    |
|   | Notes home, calls, parent--teacher conferences focused on          |
|   | behaviour rather than academics. You may dread checking his        |
|   | folder.                                                            |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🙋 | **Calls out or disrupts the class**                               |
|   |                                                                    |
|   | Shouts answers, makes jokes at inappropriate times, gets out of    |
|   | his seat, or distracts classmates. He's not being defiant --- he   |
|   | just can't contain the impulse.                                    |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| ✍️ | **Messy handwriting or avoidance of writing tasks**               |
|   |                                                                    |
|   | Fine motor control and the sustained focus required for writing    |
|   | combine to make written work especially frustrating.               |
+---+--------------------------------------------------------------------+

  -----------------------------------------------------------------------
  **LESS OBVIOUS SIGNS --- 10 SIGNS**

  -----------------------------------------------------------------------

+---+--------------------------------------------------------------------+
| 🌙 | **Difficulty falling or staying asleep**                          |
|   |                                                                    |
|   | His brain doesn't seem to have an off switch at bedtime. He may    |
|   | toss, turn, get up repeatedly, or take an hour or more to fall     |
|   | asleep.                                                            |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎮 | **Hyper-focuses on preferred activities**                         |
|   |                                                                    |
|   | Can spend hours absorbed in Legos, video games, or a favourite     |
|   | topic --- but can't focus for five minutes on homework. This isn't |
|   | a choice; it's how ADHD brains allocate attention.                 |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🩹 | **Accident-prone and frequently injured**                         |
|   |                                                                    |
|   | Bumps into things, falls off chairs, trips over his own feet. May  |
|   | have more ER visits, bruises, and scrapes than peers.              |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🍽️ | **Picky eating or eating very quickly**                           |
|   |                                                                    |
|   | May eat impulsively (too fast, too much) or be extremely selective |
|   | about food. Mealtimes can be a battleground.                       |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💧 | **Sensory sensitivities**                                         |
|   |                                                                    |
|   | Certain fabrics, tags in clothing, loud noises, or bright lights   |
|   | may be intolerable. Sock seams and shirt collars can cause major   |
|   | distress.                                                          |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| ⏱️ | **Poor sense of time**                                            |
|   |                                                                    |
|   | Five minutes and an hour feel the same. He consistently            |
|   | underestimates how long things take and has no internal sense of   |
|   | urgency about time.                                                |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🎤 | **Excessive noise-making (humming, tapping, clicking)**           |
|   |                                                                    |
|   | Produces a constant low-level stream of sounds, often without      |
|   | being aware of it. This can disrupt classrooms and family life.    |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 💡 | **Extraordinary creativity and divergent thinking**               |
|   |                                                                    |
|   | ADHD brains often make unique connections. You may notice wild     |
|   | imagination, inventive play, and an ability to think outside the   |
|   | box that his peers don't have.                                     |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| ❤️ | **Deep empathy and emotional sensitivity**                        |
|   |                                                                    |
|   | Despite the outbursts, he may be deeply caring and perceptive      |
|   | about others' feelings --- sometimes overwhelmingly so.            |
+---+--------------------------------------------------------------------+

+---+--------------------------------------------------------------------+
| 🧲 | **Seeks intense stimulation**                                     |
|   |                                                                    |
|   | Gravitates toward fast-paced, high-stimulation activities          |
|   | (screens, rollercoasters, loud music) and finds calm environments  |
|   | unbearable.                                                        |
+---+--------------------------------------------------------------------+

What to Do Next

If many of the signs in this catalogue feel familiar, it's worth
reaching out to your child's paediatrician or a developmental
specialist. A comprehensive evaluation typically involves parent and
teacher questionnaires, behavioural observation, and sometimes cognitive
testing.

Early identification matters --- not to label your child, but to unlock
the right support. Children with ADHD thrive when their environment,
routines, and expectations are adapted to the way their brain works.

Remember: ADHD is not a flaw. Many of the traits that create challenges
--- high energy, creativity, divergent thinking, emotional sensitivity
--- are also real strengths when supported well.
